# Projet 5 — Déploiement standardisé d'un poste de travail

## Introduction

Pour ce projet, le but était de préparer un poste informatique afin de pouvoir ensuite reproduire la même installation sur plusieurs ordinateurs. L'objectif était donc de gagner du temps en utilisant une image système plutôt que de refaire toute l'installation manuellement.

Pour réaliser ce travail, j'ai choisi d'utiliser **Clonezilla**.

## 1. Nettoyage du disque

J'ai commencé par préparer le poste qui allait servir pour le projet.

La première étape a été de **nettoyer le disque** afin de repartir sur une base propre. Cela permet d'éviter de garder des fichiers ou des anciennes données qui ne sont plus nécessaires.

Avant de continuer, j'ai également réalisé une **sauvegarde des données importantes** afin d'éviter de les perdre pendant les différentes manipulations.

## 2. Préparation de Clonezilla

Ensuite, j'ai préparé une **clé USB avec Clonezilla** afin de pouvoir démarrer l'ordinateur dessus.

Clonezilla permet de créer une image complète d'un disque et ensuite de la restaurer sur un autre ordinateur. C'est donc l'outil que j'ai choisi pour réaliser le déploiement du poste.

J'ai préparé la clé USB bootable et j'ai pu accéder à Clonezilla pour commencer la procédure.

## 3. Tentative d'installation sur la nouvelle machine

Après avoir préparé le poste de référence et la clé Clonezilla, je devais normalement passer à l'étape suivante : **installer/restaurer l'image sur une nouvelle machine**.

C'est à cette étape que j'ai rencontré un problème.

Lorsque j'ai essayé d'installer l'image sur la nouvelle machine, **l'installation ne fonctionnait pas correctement**. J'ai essayé de poursuivre la procédure, mais je n'ai pas réussi à terminer l'installation.

À cause de ce problème, je n'ai pas pu aller jusqu'au bout du TP.

## 4. Travail réalisé

Même si le projet n'a pas pu être terminé, j'ai quand même réalisé plusieurs étapes :

* Nettoyage du disque ;
* Sauvegarde des données ;
* Préparation de la clé USB ;
* Installation/préparation de Clonezilla ;
* Préparation du déploiement de l'image ;
* Tentative de restauration sur une nouvelle machine.

La partie qui n'a pas pu être terminée est principalement le **déploiement de l'image sur la deuxième machine**.

Je n'ai donc pas pu effectuer les dernières étapes qui consistaient à vérifier que la nouvelle machine était identique au poste de référence et à comparer le temps d'installation avec une installation classique.

## Conclusion

Ce TP m'a permis de comprendre le principe du déploiement d'un poste à partir d'une image système. J'ai pu découvrir et utiliser Clonezilla ainsi que les différentes étapes nécessaires avant de pouvoir déployer une image.

Cependant, j'ai rencontré un problème lors de l'installation sur la nouvelle machine, ce qui m'a empêché de terminer le TP.
